core abilities

把复杂的模型世界，整理成一张清晰的桌面。

API 中转站提供统一接口、智能路由、用量统计与权限管理等能力。首页只负责迎接用户，真正的工作交给后面的控制台。

适用于自用、团队内部和企业私有化部署场景。具体可用模型和权限，以当前实例配置为准。

统一入口

用一个清楚的入口承接多种模型与接口格式，减少应用侧的重复适配工作。

智能路由

按渠道权重、失败重试与限流策略安排请求，让调用链路更有秩序。

用量洞察

围绕调用、额度与成本做可视化管理，方便团队复盘资源使用情况。

团队权限

通过令牌、模型访问控制与组织内权限配置，把每个调用者放在合适的位置。

how it flows
