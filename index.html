before you start

关于这个首页的几个小问题。

页面本身不保存账号、不调用模型，只负责展示入口和引导。

这个页面怎么接入 New API？

把本页面部署到 GitHub Pages 后，复制它的 HTTPS 地址，在 New API 后台的首页内容设置中填入这个地址。New API 会将这个 URL 作为全屏 iframe 首页加载。

“开始使用”会跳到哪里？

页面会读取 iframe 外层的 New API 来源地址，并把按钮自动指向外层实例的注册页。直接打开 GitHub Pages 预览时没有外层实例，按钮会停留在当前说明区域。

页面支持 New API 的深色模式吗？

支持。New API 会通过 postMessage 发送 themeMode，页面收到 light、dark 或 system 后会同步颜色主题。

可以修改成自己的品牌名吗？

可以，直接修改 HTML 中的标题、品牌文字和页脚文字即可。页面没有构建工具，改完提交到 GitHub Pages 就能生效。
