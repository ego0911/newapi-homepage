before you start

关于这个首页的几个小问题。

页面本身不保存账号、不调用模型，只负责展示入口和引导。

这个页面怎么接入 API 中转站？

把本页面部署到 GitHub Pages 后，复制它的 HTTPS 地址，在 API 中转站后台的首页内容设置中填入这个地址。支持 iframe 首页的实例会将这个 URL 全屏加载。

“开始使用”会跳到哪里？

页面会读取 iframe 外层实例的来源地址，并把按钮自动指向外层实例的注册页。直接打开 GitHub Pages 预览时没有外层实例，按钮会停留在当前说明区域。

页面支持中转站的深色模式吗？

支持。外层页面可以通过 postMessage 发送 themeMode，页面收到 light、dark 或 system 后会同步颜色主题。

可以修改成自己的品牌名吗？

可以。页面会优先读取 URL 中的 siteName 参数，或父页面通过 postMessage 传入的站点名称；没有名称时会根据外层域名生成通用名称。由于 GitHub Pages 与外层站点通常跨域，页面不能直接读取外层导航左上角的 DOM 文本。
